# SOFY

> SOFY is an AI-powered software testing platform that autonomously writes, executes, and maintains no-code tests across mobile (2,000+ real devices), web, API, and enterprise (SAP, Dynamics 365) applications. Its public API drives build uploads and scheduled test execution from CI/CD pipelines. This llms.txt was generated by the API Evangelist enrichment pipeline from the public SOFY documentation.

## APIs
- [SOFY Public API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/sofy/refs/heads/main/openapi/sofy-public-api-openapi.yml): Upload builds, trigger/monitor/abort scheduled test runs. Base host https://public.sofy.ai; auth via x-sofy-auth-key header.
